# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [1.0.0] - 2026-08-10

### Added
- Initial release of the `commit-breaker` GitHub Action.
- Translates your GitHub contribution graph into an animated Breakout game.
- Simulates paddle and ball physics to clear contribution bricks.
- Outputs crisp SVG and optimized GIF formats.
